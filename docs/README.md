# JenuelDev repository documentation

This repository contains Jenuel Ganawed's portfolio, blog, and related public assets.

| Project | Directory | Stack | Public site |
| --- | --- | --- | --- |
| Portfolio | [`www/`](../www/) | Vue 3, TypeScript, Vite, UnoCSS, Sass | <https://www.jenuel.dev/> |
| Blog | [`blog/`](../blog/) | Astro, TypeScript, Supabase, UnoCSS, Sass | <https://blog.jenuel.dev/> |
| Store pages | [`gumroad/`](../gumroad/) | HTML templates | <https://store.jenuel.dev/> |

Start with [local development](development.md). Read [architecture](architecture.md) for the source map and [blog design](blog-design.md) when changing the blog's appearance.

The root `README.md` also serves as a public profile. Its latest-post list is maintained by `.github/workflows/blog-post-workflow.yml`. Keep project documentation here so that profile content remains intact.
